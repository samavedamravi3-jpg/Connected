# Guardrails and misuse controls

Layers (all on public free text): client check (`src/lib/moderation.ts`) -> DB triggers (`moderation_is_clean`, generated by `scripts/gen-moderation-sql.ts`) -> optional server AI check (`server/src/index.ts`, `/moderate`, Groq or Claude).

## What happens when something is unavailable
| Situation | Result |
|---|---|
| `EXPO_PUBLIC_ASSISTANT_URL` unset | AI layer skipped. Word list and DB triggers still apply. |
| Server up, no `GROQ_API_KEY` | Falls back to Claude (`ANTHROPIC_API_KEY`). |
| No provider key, provider error, timeout or unclear answer | `/moderate` returns 503. Borderline text (money, links, contact words) is refused with "Try again in a moment". Ordinary text is unaffected. |
| Server unreachable | Same as 503. |
Affected sends: assistant question, connection-request message, chat message, experience entries. Profile text and chips use local + DB checks only.

## Misuse controls
- Reports: one per reporter per subject; 3 distinct reporters auto-hide a profile (events via `hidden_event_ids()`). Restore: `update public.profiles set hidden = false where id = '<uuid>';`
- Hidden accounts cannot send connection requests (`account_restricted`). Profile rows cannot be deleted by users.
- Rate limits (`rate_check`): requests 10/day strict (new <24h or unverified), 15 trusted; profile text edits 120/hour; reports 10/30 per day. Strict values were raised for the demo (production: 3 requests/day, 30 edits/hour).
- Mutes hide someone from alerts server-side; map/search use local state.
- Review queue: `select * from public.admin_review_queue;` (SQL editor / service role only). Audit trail: `public.audit_log`.

## ID verification gate
`app_config.id_gate` is `off`. Turn on only after Stripe works: `update public.app_config set value='on' where key='id_gate';`

## Known limits
- Three throwaway accounts can still auto-hide a profile (reports are not weighted by verification).
- Open Door limits are client-side (doors live on the phone).
- "cum" is blocked, so "magna cum laude" is rejected.
