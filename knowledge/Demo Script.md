# Demo Script

## 60–90 seconds
1. **Problem:** “Most networks assume you already know someone. Connected helps you make the first useful connection.”
2. **Intent:** Create a demo profile: goal “Get my first banking internship”, field Finance, help “Interview practice”.
3. **Discovery:** Explore the NYC demo. Filter by J.P. Morgan; open James Wilson. Clearly identify it as a fictional demo profile.
4. **Reason:** Show that James explicitly offers internship advice and interview practice.
5. **Action:** Draft and edit a short introduction. Save a demo request. It remains pending and does not pretend a real person accepted.
6. **Community:** Explore events and Flatiron hotspots. Demonstrate saving an event.
7. **Control:** Explain optional, approximate, one-hour discovery and the separate live community mode.
8. **Close:** “A goal, a willing person, and one conversation. That’s how a network starts.”

## Before presenting
Confirm network access for map tiles. Have the sample city ready. If the Anthropic key is not configured, explain the template fallback honestly. Do not show a key or claim demo affiliations are real.
